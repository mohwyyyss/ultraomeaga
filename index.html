Hiddenmolty on Telegram

What it is

Hiddenmolty is a Telegram bot powered by an open-source large language model (Qwen3.8-27B). It runs on cloud GPUs and answers right inside your Telegram chats, so the AI you already talk to every day is simply there when you need it.

It is built for people who want a capable assistant without handing their conversations to an advertising company. Your chats stay between you and the model.

Features

Private by design

No ads, no data selling, no third-party analytics. Conversations are used only to answer you.

Persian & English

Fluent in both languages, with natural Persian replies — not translated English.

Memory

It remembers the facts and preferences you choose to share, across conversations.

Tools

It can read and write files and run commands in its own workspace to get work done, not just chat.

Open models

Built on open weights (Apache 2.0), so the model itself can be inspected, audited and self-hosted.

Adjustable effort

Quick answers when you want speed, deeper reasoning with self-checks when the question matters.

How it works

  1. Open Telegram and start a chat with @Hiddenmoltybot.
  2. Ask anything, in Persian or English.
  3. Use /remember to save a fact, or just keep chatting — it picks up the context.

About

Hiddenmolty is an independent solo project. It is built on open-source software, runs on cloud infrastructure, and is funded by its developer — no venture capital, no ads, no data selling.

The project is under active development. Access is currently limited to private testing while the assistant is being refined.
